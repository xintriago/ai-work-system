# AGENTS.md

## Mandatory Engineering Standard
All coding agents working in this repository must read and follow `ENGINEERING_STANDARD.md`.

Implementation is not completion. Execute applicable quality, security, integration, staging, and council gates and update `VERIFICATION_REPORT.md` with evidence before claiming readiness.

Use only these readiness levels: CONCEPT, SCAFFOLD, IMPLEMENTED, LOCALLY_VERIFIED, INTEGRATION_VERIFIED, STAGING_VERIFIED, PRODUCTION_VERIFIED.

A critical/high security issue, authorization or tenant-isolation failure, required failing test/build/migration, exposed secret, unverified consequential/payment flow, or required placeholder is a release blocker.
